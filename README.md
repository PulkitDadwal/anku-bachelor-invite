# Akanksha's Twilight Toast 🎀
### Cheri Cheri Lady — Interactive Flip Invitation Card

A luxury interactive wedding / celebration card built with React, Vite, and Tailwind CSS. Featuring realistic 3D page turns, a live countdown timer, ambient music synthesizer, celebratory confetti, and guest RSVP blessings wall.

Ready for 1-click deployment on **Vercel** with zero backend required!

---

## ✨ Features

- **📖 Realistic Page Turning Experience**:
  - **Cover Page**: "Celebrating our ultimate Cheri Cheri Lady! 🎀" featuring Akanksha's photo and shimmering ribbon details.
  - **Invitation Page**: "Akanksha's Twilight Toast" with event details (Nov 21, 2026, 7 PM, Manhas Residence) and one-tap calendar / contact shortcuts.
  - **Countdown & QR Page**: Live ticking countdown timer (Days : Hours : Mins : Secs) dynamically counting down to November 21, 2026, 7:00 PM IST + tappable QR code.
  - **Blessing & Wishes Page**: Interactive RSVP and guest wish wall with local storage persistence.
- **📱 Fully Responsive**: Seamless touch swipe gestures on mobile (iPhone & Android) and smooth keyboard/arrow controls on desktop.
- **🎵 Built-in Ambient Music Synthesizer**: Uses Web Audio API to play romantic chimes and realistic paper rustle sound effects without external audio files.
- **🎉 Confetti & Sparkles**: Custom pink, gold, and white confetti bursts when opening the card and celebrating.
- **🚀 Frontend Only**: Pure client-side SPA. Deploy to Vercel, Netlify, or GitHub Pages in seconds.

## 🚀 Running Locally

```bash
# Navigate to the project folder
cd twilight-toast

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to Vercel

### Option 1: Via Vercel CLI (Fastest)
```bash
# Install Vercel CLI if needed
npm i -g vercel

# Deploy directly
vercel
```

### Option 2: Via GitHub & Vercel Dashboard
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository.
4. Framework Preset will auto-detect **Vite**.
5. Click **Deploy**! ✨
